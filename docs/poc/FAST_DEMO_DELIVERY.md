1. Cursor Push PR 的 `READY_FOR_REVIEW` 可与用户真人企微 UAT **并行**；用户反馈立即建 Issue/PR Fix，不必等本轮完整 Review 才让 Cursor 收下一个任务。
2. **可快速 Merge**：docs/SOP 文案/排版/只读查询/不涉及身份与写入的差异，以及有独立契约、编译、负例和回归证据的窄范围功能。真实金额/库存/主数据更改路径，只做**关键风险快速 Review**即合并，不以人工真人 UAT 已完成作为 GitHub Merge 的必要前置；UAT 结果在后续缺陷任务收口。
