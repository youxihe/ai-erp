# AIERP-020D · ERP 经营总览（企微原生卡片优先，不新增 H5）

**状态：PLANNED / single-agent queue after 020C → 020B；不允许与前序任务并行编码。**

## 核心用户体验
用户在企微说“看一下本月经营情况”：
1. 机器人以**ERP 当前授权用户**查询本月截至今日的真实数据；返回一张轻量经营总览卡，优先 6 项：本月已审核采购金额、销售金额、当前在库 SKU 数、低库存预警数、可见供应商数、可见客户数。
2. 有权限且真实数据可用的指标显示数值、单位和统计时间；无权限显示“无权限”、数据源未实现显示“暂未接入”，**不能填 0 或由模型编数字**。本月销售统计口径需明确：销售订单/销售出库/回款为三个不同指标，MVP 默认**已审核销售出库金额**，若 ERP 真实数据源尚未检验则保留“未接入”，不把 SERVICE 出库当销售。
3. 卡片提供“采购分析、销售趋势、库存分布、客户/供应商统计、刷新”只读操作。如果当前 Bot WS 支持可信交互事件，卡片按钮可触发授权查询和图表；否则用户输入对应中文短语，机器人返回 PNG 图表或表格/XLSX；**无需 H5/内网 URL**。
4. 一个指标点进详情时复用 020C table/bar/line/pie/delta 模板，Java 提供经过授权的 datasetRef；020B 提供企微 card/image/channel adapter，不新写独立报表渲染。
5. 卡片本身不显示长明细，不强行把六个指标塞进一种不支持的卡片 msgtype；真正受限时采用一张高 DPI 经营总览图片 + 后续独立图片/文件。飞书用独立 channel adapter。

## 最少 ERP 真实统计 API
- `dashboard.summary` 单次受控聚合：返回 `asOf,period,tenantScopedActor,metrics[],permissionFlags,sourceRefs`。
- 现有已审核采购 `AierpWecomQueryService.purchaseInSummary` 可以复用；仓库库存聚合必须按真实仓/单位和物料 SKU 授权范围，并区分 stock value 是否有成本计价来源。
- 供应商与客户档案 count 要基于 **当前 ERP 用户的真实可见权限**，不能只是租户总表计数。统计“活跃”要事先确定有效定义（有审核交易/有效档案不同）。
- 销售统计只聚合真实原生 SALES 类型的已审核单据，绝不能将 `sub_type='其它'` SERVICE 耗料混进销售额。销售金额的税额/币种/退货抵扣口径要在 card 下方用简短说明标清。
- 一切用户级 query cache 要加 tenant/actor/bot/binding_generation 和授权仓库版本，撤权失效，不共享给别的企微发送者；近实时数据显示最后刷新时间，出错展示上次值必须明确“历史缓存”而非实时。

## 验收
- 本月六指标来自真实 ERP，可以从 PC 后台/SQL 对账；跨用户/仓/租户严格不同，不能浏览别人的金额或客户资料；
- 销售未接入时是“未接入”，没有销售数据时才是“¥0”；已审核采购与待审核单据分开；
- 经营总览在企微 PC/手机实际可读，关键金额与状态突出、卡片按钮或对话下钻不触发任何写操作；
- 采购供应商金额柱状图、分仓库存图、时间趋势与表格均使用 020C 真实授权数据、PNG/Excel 实际送达，不附内网链接；
- **不投入独立 H5 前端**；复杂筛选/编辑需求实际出现再单独评估。
